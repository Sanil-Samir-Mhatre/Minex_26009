This directory contains raw and processed data files.
Real satellite, geological, and weather data should be placed here.
See README.md for data preparation instructions.

Subdirectories:
- satellite/   → Sentinel-2 GeoTIFF or processed CSV files
- geological/  → GSI shapefile or GeoJSON
- weather/     → ERA5 NetCDF or CSV exports
- operational/ → MOIL production records CSV
- processed/   → Feature-engineered output files

Note: Large raw data files are not committed to version control.
